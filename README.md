## 🚀 How to Run

1. Make sure Python 3 is installed:
   ```bash
   python --version
   ```
2. Clone the repository:
   ```bash
   git clone https://github.com/Sumit190-glitch/Python-Project.git
   cd Python-Project
   ```
3. Run any file:
   ```bash
   python filename.py
   ```
